# 状态图标 v1 · 交戦圆章改稿

本轮只制作 **交戦 / `engaged`**。本次改为 **石墨灰实心圆章＋象牙色交叉太刀＋浅金外圈**，避免与武田红底色接近，同时利用亮色外圈在炭灰底上保持轮廓。圆章尽量填满 **100 × 100** 的显示区域，外侧透明；尚未接入 TTS Global Lua。

[查看总览](./总览.jpg) · [100 × 100 PNG](./engaged-100.png) · [512 PNG](./engaged.png) · [1024 源图](./源图/engaged-1024.png) · [manifest.json](./manifest.json)

## 文件与尺寸

| 文件 | 像素尺寸 | 透明留白（左 / 上 / 右 / 下） | 用途 |
| --- | --- | --- | --- |
| `engaged.png` | 512 × 512 | 3 / 3 / 3 / 3 px | 保留稳定接入路径的透明 RGBA PNG |
| `engaged-100.png` | 100 × 100 | 0 / 0 / 0 / 0 px | 按建议显示尺寸直接导出的 PNG |
| `源图/engaged-1024.png` | 1024 × 1024 | 10 / 11 / 10 / 11 px | 高分辨率透明版本，便于后续调整 |

留白按 alpha > 0 的像素外接矩形测量，包含低透明度抗锯齿边缘。100 px 版本的抗锯齿像素延伸到画布边界，主体圆边仍留约 1 px 余量，四角透明。圆章内部为实心底色，圆外透明；没有文字。建议保持原有颜色，不对整张图片乘黑色或降低透明度。

以 **1200 × 1200** 棋面、左上角为 `(0,0)`：显示画布 **100 × 100**，左上角 **`(20,56)`**，中心 **`(70,106)`**。此处记录的是整张 PNG 画布的位置，不要按可见轮廓重新裁切定位。

## 代码侧交接

- 固定标识：`engaged`；建议引用 `manifest.json` 中的路径、像素尺寸与定位。
- 本次为 `revision: 3`，更新圆章配色；沿用 revision 2 的 100 × 100 px、左上 `(20,56)`、中心 `(70,106)`。代码侧替换图片并更新资源版本／缓存即可；若仍使用 revision 1，则按当前 manifest 同步尺寸与定位。
- `cloud_url` 当前为空。仓库预览链接不代表已配置或已验证的 TTS 图片资源；需要代码侧选定图片托管、登记资源并验证加载。
- 由代码侧实现状态保存／恢复、显示／隐藏和触发方式；本稿不提供自动判定交战或回合清除规则。
- 1200 棋面像素坐标需映射到实际物件坐标／UI。已有正背面渲染方式、厚度偏移及资源登记顺序请按代码侧交接保留，不能直接把本文件的像素数当作 TTS 世界坐标。
- 实机检查应覆盖正反面、多人、缩放、倾斜和移动后的透明排序，并确认图标不拦截既有操作区域。
- 其余标识 `out_of_command`、`formation_close`、`formation_open`、`fire_ready`、`fire_loading`、`routed` 本轮尚未制作。没有导出占位图，也没有把其他状态当作已完成。
