# 部队素材 · 12 种

[下载全部素材 ZIP](./部队素材_12种.zip) · [查看效果总览](./总览.jpg)

这些素材由 128 × 236 像素原图经 AI 高清重绘，并补全右侧缺失部分。细节可能与原低分辨率图略有差异，并非无损恢复。保留原有左侧、底部的半身裁切，不补成全身。

人物按自然的头身比例统一大小，主体位于底图大方框左半；马匹、手臂和武器可伸入右半。長柄足軽隊的三间枪尽量延长至适合整个大方框的长度。

## 使用方法

- **底图定位**：均为 1200 × 1200 像素透明 PNG。在 Photoshop 中按原尺寸 **100%** 放入，并与画布左上角对齐，即可叠加到 [素材/底图](../底图/) 中的任一底图。大方框以外完全透明。
- **高清透明**：独立透明 PNG，可自行调整大小和位置。
- **预览**：带金色底图的效果参考 JPG，不是透明素材。
- **ZIP**：`部队素材_12种.zip` 包含高清透明、底图定位、预览和本说明。
