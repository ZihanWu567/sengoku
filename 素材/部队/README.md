# 部队素材 · 12 种

[下载全部素材 ZIP](./部队素材_12种.zip) · [查看效果总览](./总览.jpg) · [原图与新版对照](./原图对照.jpg)

以用户提供的 128 × 236 像素原图为依据，按**统一 4 倍的原图构图**进行高清重绘，并补齐右侧缺失轮廓。尽量保留原来的脸型、姿势、装备、配色与纹样；左侧、底部沿用原有裁切。全部素材使用同一画布变换，保留原图各兵种的相对大小，不按单张人物的头部或轮廓单独缩放。

長柄足軽隊保留原枪杆方向和握持姿势，继续加长三间枪；枪尖延至画布外，木质枪杆由大方框上边缘截断。其余原本完整的兵器不另行延长。补全以缺失边缘为限；低分辨率原图无法辨认的细节仍会有重绘差异，可通过对照图检查。

## 使用方法

- **底图定位**：均为 1200 × 1200 透明 PNG。按 100% 大小与底图画布左上角对齐，可直接叠加到[任一底图](../底图/)。大方框之外完全透明。
- **高清透明**：均为 984 × 984 透明 PNG，统一画布并保留空白，方便保持各兵种相对大小。对应底图中的位置为左上角 x=14、y=202。
- **原图参考**：原始 TGA 无损转换的 128 × 236 PNG，便于核对和后续编辑。
- **预览**：使用金色底图的效果 JPG。**原图对照**中，每组左图为原图同倍率放大，右图为高清重绘与补全结果。
- **ZIP**：包含上述图片、总览、对照图与本说明。
