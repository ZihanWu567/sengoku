# 交戦／指揮外：接口与布局

更新日期：2026-10-25，当前v2.18.3。功能自v2.15.0接入：手动状态标记、所有玩家可切换、两面共享并保存；图标位于顶栏两端，关闭时淡显。本次保留用户当前存档的新指揮外竖图直链，保留独立宽高，并按最新实机反馈，相对v2.18.2将两图上移5，仅指揮外右移5个棋面像素。

## 操作与规则边界

配置图片后，左键「交戦」图标切换交戦，左键「指揮外」图标切换指揮外；再点一次关闭。右键不改变状态，没有新增快捷键、右键菜单或悬停提示。

两项独立，允许同时启用，正反面与所有玩家共用同一枚棋子的记录。没有自动判断邻敌、接战、指挥路径，也不自动扣移动力、士气或阻止操作。

移动、翻面、士气归零／恢复、敗走以及未／済切换都保留手动标记，玩家需按规则自行解除。程序接口 `resetUnit()` 是完整重置，会同时清除两项标记；士气快捷补满不等同完整重置。

存档在现有 `unit_state[GUID]` 增加 `engaged`、`out_of_command`。旧存档缺字段或值不是布尔true时默认为false，不修改已有士气或行动状态。没有标记不代表程序已经验证该部队处于指挥范围。

## 美术侧交付与代码侧接入

每项只需**一张透明PNG**：

| 固定标识／建议文件名 | 用途 | 棋面中心坐标 |
| --- | --- | --- |
| `engaged` / `engaged.png` | 交戦，图形仍按美术定稿 | X77，Y115 |
| `out_of_command` / `out_of_command.png` | 指揮外，用户上传的竖向剪影 | X940，Y105 |

上述坐标基于完整1200×1200棋面，左上角为原点。交戦仍显示100×100、点击120×120；指揮外显示125×200、点击125×200。已读取当前TTS缓存，指揮外源PNG为320×512，透明包围框(24,41)～(302,481)，其比例恰好匹配新图框，不会拉伸人物。两枚的可见内容仍在1000×200标题区域内，不占右上未／済格。

交戦图片范围X27～127/Y65～165、点击X17～137/Y55～175。指揮外图片及点击范围X877.5～1002.5/Y5～205；实际可见内容约X887～995.5/Y21～193，仍在顶栏内。按用户指定宽高保留，透明点击区在右栏边界多出2.5像素。文字建议控制在X147～867，避开透明点击区域。现有四字／五字名称已画进底图，本轮没有修改96张成品；标题留位与极斜视角仍需实机检查。

图标启用时使用 `#FFFFFFFF`，保留原色和100%不透明度；关闭时使用 `#FFFFFF20`（约13%不透明度）。两面顶栏仍是家族底色，因此不需要另出象牙白或背面版本，也不需要单独绘制关闭态。半透明乘色基于 [TTS UI颜色属性](https://api.tabletopsimulator.com/ui/attributes/#attribute-types)。

上传正式PNG至可供所有玩家访问的云端后，在 `tts/Global.lua` 顶部填写纯直链：

```lua
UNIT_STATUS_IMAGES = {
    engaged = "",        -- 填交戦 PNG 的 https:// 直链
    out_of_command = ""   -- 填指揮外 PNG 的 https:// 直链
}
```

不要填写本机路径、Markdown链接包装、仓库blob页面或臆造的地址。只填其中一张时仅显示相应标记；清空图片不会删除存档中的状态。`runtime-assets.json`只是源码配置快照，不被游戏读取。

填写后运行同步工具，使用完整Global执行Save & Play。位移、大小和淡显颜色集中在 `UNIT_STATUS_LAYOUT`；`out_of_command`子表独立配置`width/height/hit_width/hit_height/y`，未设的项回退共享`size/hit_size/y`。图片与透明按钮使用同一尺寸解析函数，修改时保持两者同步。

## 实现与维护

- 回调：`toggleUnitEngaged(obj, player_color, alt_click)`、`toggleUnitOutOfCommand(...)`；直接调用可以操作后台状态，即使尚未配置图片。通常由已显示图标上的透明经典按钮触发。
- 正反面图标放入Object.UI，使用 `sgub_status_front`、`sgub_status_back` 根节点；图片资源名为 `sgub_status_image_engaged`、`sgub_status_image_out_of_command`。复用已有背面栏的登记、等待、更新与清理机制。
- 正面顶栏旋转 `0 0 180`，背面 `180 0 0`。正面离实体表面0.001；背面沿用已校准 `back_ui_clearance=-0.099`。旧数字、士气色带、行动与阵旗偏移未改。
- 图标与经典按钮均使用同一棋面坐标换算。原按钮0～5保留，新状态按钮按回调／正反面识别，避免可选图片改变固定索引。
- 图片与XML准备完成才建立新点击区；等待时不重复创建任务，完成时重新读取最新状态。普通切换只改UI属性，不重建XML或重复登记图片。
- 缺图不会退回Text或白色占位；全部节点透传鼠标，清理只处理本模块节点、图片资源及按钮。
- `commanders.lua`本轮仅同步版本头，独立武将面板没有新增部队功能。当前安装入口为 `tts/Global.lua` 或同内容 `tts/releases/Global_v2.18.3.txt`。

已知限制：旧加载流程不能登记相同图片URL两次；用户已通过更换重复图片解决，明确不继续改该流程。本轮保留两张不同地址。新增底部接口另见 [UNIT_MODES.md](UNIT_MODES.md)。
