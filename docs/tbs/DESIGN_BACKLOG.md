# 最新设计记录：全部尚未实现

整理日期：2026-10-21。来源为本会话中的用户明确需求／修正。这里没有完整可运行的“新状态版”脚本；不要把下列讨论误报为已经接入v2.14.11。

## 已明确的方向

1. **交戦与指揮外**可用战国风图标，不强求文字。讨论中的图形为交叉日本长枪、军配＋斜杠；最终图样尚未制作确认。
2. 顶部标题存在四字和五字兵种名，状态图标应固定位置，名称居中，不随状态出现左右移动。既有标题已烘焙在底图，任何缩小／留位都需另开美术变更，导入任务不能覆盖96张成品。
3. **散開／密集**在底部右侧、右侧数值栏左边，以两张不同图片切换；不是只在散開时出现。建议用相同数量的兵位、不同间距表达，最终图样待制作。
4. **射击准备／装填中**也用两张图切换，放在同一位置。用户明确认为离弦箭、枪口烟不够清楚，要表现装填过程。
5. **所有远程共用铁炮两图**，不用分别制作弓、铁炮、大筒三套：准备完成为横向待射火绳枪，装填中为枪口朝上、通条插入的动作。只是视觉约定，不擅自禁止原规则允许的反应射击。
6. **敗走可用大图标**，不强求「敗走」文字。需地图上明显、有武将叠放不被挡、没有武将也协调。用户提出可用图片或TTS功能抬高显示。
7. 最近建议为小幅悬浮、平行棋面的大标记：无武将贴近部队，有武将略高于顶面，位置／尺寸固定。倒伏无家纹军旗＋后退双箭只是提案，尚非用户确认的成品。
8. 陣旗表示所属，不能为了敗走而删除家纹／变更归属旗；阵旗史实化改造暂后置。

## 仍属布局提案的数值

- 以1200棋面计，顶栏1000宽，左右图标约100见方，中心约X70／X930，标题可用X140～860；这些未修改底图或代码。
- 散開／射击状态标记约220～260宽、110～130高，放在底部露出边缘内。
- 纯图形敗走章曾建议360～420宽、220～260高，或较宽的横牌；最终大小须看游戏内缩远和叠放效果，未定稿。
- 原先“三种武器分别表示装填”“所有状态集中底部”“敗走必须文字横牌”等方案已被后续讨论调整，不作为当前要求。

## 实现前需要设计的行为

- 新状态如何写入unit_state、加载旧存档时默认什么、如何区分已有正反面损耗与行动。
- 近战显示阵形组，远程显示射击组；某些特殊兵种的归类须明确，不靠名字模糊匹配。
- 阵形／射击切换需服从最终确认的规则限制；回合恢复清射击不能顺便清Engaged或散開。
- 指揮外初版可手动标记；自动化需正确的六角格、阻挡、ZOC及同隊传递数据。
- 叠放检测仅考虑相关武将，不能因邻棋、桌面装饰或拖拽中的物件任意抬升。标记不拦截点击，不远离所属棋子。
- 两面、多人、缩放、移动、保存／加载和不同视角都要验收；复用已稳定的背面UI资源登记方式，避免再引入共面贴花闪烁。

## 推荐拆分PR

先对齐兵种／美术表和规则默认值；再实现两态数据与面板操作并验证旧存档迁移；然后接入最终图标；最后单独处理叠放高度和远距离敗走识别。完整RAN回合自动化另开任务，不混入这次资源导入。
