# 最新设计记录与完成边界

更新日期：2026-10-23。v2.17.0已实现散開TQ−1、保留累计损伤、阈值减弱、换阵未／済联动和士气上限悬停提示。已接入当前存档的密集／散開图片与底部布局；射击两图仍空。其余规则自动化及悬浮敗走仍未实现，见 [UNIT_MODES.md](UNIT_MODES.md)。

## 已明确的方向

1. **交戦与指揮外**采用图片，关闭时淡显、左键切换、右键忽略，两面共享并保存。当前仅手动标记，不自动判定或施加规则；图片未填不显示文字或点击区。交叉日本长枪、军配＋斜杠仍是图形提案，最终图样尚未制作确认。
2. 顶部标题存在四字和五字兵种名，状态图标应固定位置，名称居中，不随状态出现左右移动。既有标题已烘焙在底图，任何缩小／留位都需另开美术变更，导入任务不能覆盖96张成品。
3. **散開／密集**在底部右侧、右侧数值栏左边，以两张不同图片切换；不是只在散開时出现。建议用相同数量的兵位、不同间距表达，最终图样待制作。
4. **射击准备／装填中**也用两张图切换，放在同一位置。用户明确认为离弦箭、枪口烟不够清楚，要表现装填过程。
5. **所有远程共用铁炮两图**，不用分别制作弓、铁炮、大筒三套：准备完成为横向待射火绳枪，装填中为枪口朝上、通条插入的动作。只是视觉约定，不擅自禁止原规则允许的反应射击。
6. **敗走可用大图标**，不强求「敗走」文字。需地图上明显、有武将叠放不被挡、没有武将也协调。用户提出可用图片或TTS功能抬高显示。
7. 最近建议为小幅悬浮、平行棋面的大标记：无武将贴近部队，有武将略高于顶面，位置／尺寸固定。倒伏无家纹军旗＋后退双箭只是提案，尚非用户确认的成品。
8. 陣旗表示所属，不能为了敗走而删除家纹／变更归属旗；阵旗史实化改造暂后置。

## 已实现的行为与仍待设计的自动规则

- `unit_state.open_order/reloading` 已实现，旧存档默认false；士气／未済／翻面不会清除，完整reset恢复默认。
- 十类兵种已显式分为近战阵形组／远程射击组，包括南蛮大筒属于射击组；新增兵种需指定 `marker_mode`，不靠名字模糊匹配。
- 阵形已检查未行动、非减弱／交戦／敗走并消耗行动；邻敌／撤退判断仍由玩家负责。回合恢复清射击不能顺便清Engaged或散開。
- 指揮外初版已提供手动标记接口；自动化需正确的六角格、阻挡、ZOC及同隊传递数据。
- 叠放检测仅考虑相关武将，不能因邻棋、桌面装饰或拖拽中的物件任意抬升。标记不拦截点击，不远离所属棋子。
- 两面、多人、缩放、移动、保存／加载和不同视角都要验收；复用已稳定的背面UI资源登记方式，避免再引入共面贴花闪烁。
