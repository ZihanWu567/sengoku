# 底部阵形／射击状态（v2.16.0）

用户于2026-10-21确认：先做手动图片切换，所有玩家可操作，正反面共享并保存；非远程步骑兵显示密集／散開，远程在同一位置显示准备完成／装填中。四张新图片暂留空。

## 操作与适用兵种

配置图片后，左键底部图片切换，右键不改变；正反面显示同一状态。不是文字按钮，不新增菜单或悬停提示。

| `marker_mode` | 兵种 | 默认 → 点击后 | 存档字段 |
| --- | --- | --- | --- |
| `formation` | 長柄足軽、騎馬武士、徒歩武士、槍足軽、赤備騎馬 | 密集 → 散開 | `open_order=false/true` |
| `fire` | 弓足軽、弓僧兵、鉄砲足軽、鉄砲僧兵、南蛮大筒 | 准备完成 → 装填中 | `reloading=false/true` |

每枚棋子只显示适用的一组，不并排显示两组。兵种分类在 `UNIT_CONFIGS` 显式指定，不依赖中文名字匹配；未来增加兵种需明确填写类别，未填则不提供这个控件。

两个存档字段都是严格布尔值；旧存档缺失／无效时为false。士气、未／済、交戦、指揮外、翻面、移动、敗走、士气快捷补满都不联动这两个值。完整 `resetUnit()` 才同时恢复密集／准备完成。没有自动回合恢复、射击限制、换阵消耗或战斗修正。

换兵种Tag后，刷新会更换适用图片组；隐藏的另一组字段仍保留，换回原类别可恢复其手动记录。复制Lua不等于导入场景状态；需要正常保存TTS游戏。

## 四张素材接口

填写 `tts/Global.lua` 顶部：

```lua
UNIT_MODE_IMAGES = {
    closed = "",     -- 密集
    open = "",       -- 散開
    ready = "",      -- 准备完成：全部远程共用铁炮图形
    reloading = ""   -- 装填中：全部远程共用铁炮图形
}
```

每组两张都必须有有效的HTTP(S)图片直链。缺任意一张就隐藏整组，包括点击区域，避免切到空图后无法点回。缺图不改变已保存状态；后台回调 `toggleUnitMode(obj, player_color, alt_click)` 仍可用于脚本操作。

四张素材使用各自实际上传的地址，不用重复地址占位。新底部组若内部两地址相同，或与该物件已有UI资源地址冲突，会跳过整组并提示一次，避免重现冷加载一直等待的问题。本次没有修改用户已决定保留的旧顶栏资源加载流程。

建议透明PNG、同一画布和主体比例，源图480×220即可；显示时两态都是原色全不透明。四张图不必分别制作正面／背面版本。这里只交付接口，没有生成或上传这些图片。

顶栏两张图沿用用户实际存档中已正常使用的不同直链，已同步到新版代码和 `runtime-assets.json`。该JSON是配置快照，游戏不读取它。

## 位置与尺寸

基于完整1200×1200棋面，原点在左上：

- 中心 **X850／Y1130**，显示 **240×110**，点击 **260×130**。
- 图片范围X730～970、Y1075～1185；按钮范围X720～980、Y1065～1195。
- 右侧数值栏从X1000开始；现有旗到Y1060；叠放武将的中央覆盖区到Y1000。此位置在三者之外，保留图片下方15像素边距。
- 坐标和大小集中在 `UNIT_MODE_LAYOUT`，改参数时图片与点击区一起更新。
- 正面UI离面0.001，背面沿用已确认的 `back_ui_clearance=-0.099`。不要改动原数字栏偏移来调新图片。

正背面均加入现有 Object.UI，根节点 `sgub_mode_front/back`，子图 `sgub_mode_front_image/back_image`；经典透明按钮调用 `toggleUnitMode`，原按钮0～5保持原用途。两图提前登记，实际只显示一个Image节点；换图不增加或重建节点。

## 性能与验证边界

“合成一个UI”是同一个 Object.UI 管理多张图片，不是每次点击重新合成并上传PNG，也不能等同于只有一次GPU绘制。普通切换只写变化的Image属性；XML和资源只在初始化、配置／适用类别变化等情况下重建。没有增加每帧遍历或战场扫描，每枚仅预载所属组的两张图片、增加正反面各一个Image。

因此不能只凭“用了UI”认定更慢；也没有实际大场景FPS数据证明一定更快。首载成本与图片尺寸和网络有关，持续渲染成本仍随可见棋子及UI节点增加。保留当前稳定渲染方案，后续在真实大棋盘上测量，再决定是否需进一步优化。属性更新与XML替换是不同API，见 [TTS UI文档](https://api.tabletopsimulator.com/ui/)。

实机仍需配置四张图片后检查：两面朝向、倾斜角度、底边和旗帜间距、叠武将时的点击、多人同步，以及连续切换不白屏。离线测试不能替代这部分验收。
