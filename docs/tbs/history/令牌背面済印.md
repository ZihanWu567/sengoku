# 令牌背面「済」印：v2.9

更新：2026-10-10。v2.9 使用同一张「済」图片，在武将面板中显示行動印，并自动叠加到桌上武将令牌的背面。印章地址只在 Global 中统一设置，不需要在每枚令牌的 Description 中填写。

统一图片为你提供的[済印直链](https://steamusercontent-a.akamaihd.net/ugc/16127482967476073358/AB4E3857AE6ECD0830ECE8C32682AE244709D8B5/)。武将本身的画像继续使用各自的 `image=`，姓名、生年、統率和负伤状态也照常读取。

## 安装

1. 把当前 TTS 游戏另存为副本，保存桌上令牌和 Description 的最新资料。
2. 打开[兵種与備隊面板合并版_日本漢字.lua](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/兵種与備隊面板合并版_日本漢字.lua)，确认文件第一行包含版本号 `v2.9`，复制全部内容。
3. 在 **Scripting → Lua → Global** 中全选旧代码，以新代码完整替换，再点 **Save & Play**。不要把整份新版追加到旧代码末尾。
4. 指向任意武将令牌，检查面板与令牌背面印章。若令牌刚修改了编队资料，点击面板的「更新」。

如果游戏中的 Global 还包含你后来修改的其他功能，请先按[与现有 Global 合并方法](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/与现有Global合并方法.md)保留那些改动。

## 哪些令牌会自动贴印

只处理能识别为 `main`、`deputy1` 或 `deputy2` 的武将令牌。新建備隊也适用，例如：

```text
team=ota_honjin
role=main
name=太田資正
birth=1522
command=5
image=你的画像完整URL
status=無傷
title=備大将
formation=太田家 本陣
order=防御
```

以上 `image=` 示意内容需替换为真实画像直链；留空也不会影响背面印章功能。主将用 `main`，两位副将用 `deputy1` 和 `deputy2`。同队三人共用 `team`。

普通部队的 `role=unit` 不会自动贴印。已有十二名武将仍可按内置名单识别，但给令牌明确填写 `team`、`role` 更便于之后扩编。

旧描述里的 `acted_image=` 可以保留或删除，v2.9 会忽略它；旧地址和 `acted_image=-` 都不会改动这次统一使用的「済」图片。

## 正反面与面板

| 令牌朝向 | 面板行動 | 面板画像 | 桌上令牌 |
| --- | --- | --- | --- |
| 正面朝上 | `未` | 不显示「済」印 | 正面保持原图。 |
| 翻面 | `済` | 右下角叠加「済」印 | 背面原图上显示「済」贴花。 |

脚本始终依据令牌的 `is_face_down` 判断行動。背面贴花固定留在反面，翻回正面后被令牌本体遮住。贴印本身不更改行動状态，也不修改 `status`；浅手、深手或討死与未／済可以同时存在。

贴花叠加保留令牌原本的底图，不会从面板 `image=` 生成新的背面材质。不同物件的背面设置不同：Custom Tile 支持独立底面图片，Custom Token 的脚本参数没有独立背面图片字段。如果还想更换背面画像，应按实际物件类型设置。[官方自定义物件参数](https://api.tabletopsimulator.com/custom-game-objects/)

## 自动检查与去重

Global 在游戏加载、武将令牌新生成、悬停、放下和点击「更新」时检查贴花。脚本先读取原有贴花，保留其他贴花，再更新本功能使用的背面「済」印；反复刷新不会一直叠加同一印章。

稳定的定时面板资料刷新不再重复读取贴花和尺寸。非等比缩放令牌或手动增删／调整贴花后，重新悬停该令牌或点击「更新」，会重新校验背面印章。

本功能使用贴花名称 `SG_済_背面` 进行识别和去重。不要把其他用途的贴花也命名为这个名称；其他名称的贴花会原样保留。武将改为普通 `role=unit` 后，检查时会移除本功能的背面印章。

TTS 的 [`getDecals()`](https://api.tabletopsimulator.com/object/#getdecals) 可以读取已有贴花；[`setDecals()`](https://api.tabletopsimulator.com/object/#setdecals) 会替换整组贴花，所以本脚本保留其他贴花后再提交完整列表。贴花位置和转角相对于令牌本身，而非棋盘的固定坐标，因此移动令牌时印章随令牌移动。[官方贴花参数说明](https://api.tabletopsimulator.com/object/#adddecal)

## 大小与位置

当前默认采用你对现用令牌的实测参数：`BACK_STAMP_RATIO=1`、`BACK_STAMP_GAP=-0.09`。印章居于背面中央，直径为平面较短边的 `100%`，即短边的 `1` 倍。

需要整体调整时，在 Global 面板代码开头查找以下常量。先另存一个测试副本，再修改一个参数并检查一枚令牌；准备重新加载前，先保存游戏中的令牌资料。

| 常量 | 默认值 | 用途 |
| --- | --- | --- |
| `ACTED_IMAGE_URL` | 上述统一 URL | 面板与背面共同使用的「済」图。更换时只改这里。 |
| `BACK_STAMP_RATIO` | `1` | 印章直径为令牌平面较短边的 100%，采用当前令牌实测值。 |
| `BACK_STAMP_GAP` | `-0.09` | 局部偏移校准值，采用当前令牌实测值。 |
| `BACK_STAMP_ROTATION` | `{270, 0, 0}` | 贴花相对令牌的旋转。 |

脚本在贴花校验时按令牌的归一化视觉边界估算背面位置，并换算为局部坐标；无法取得视觉边界时使用碰撞边界。印章尺寸按令牌的平面尺寸计算，通常不必为每枚令牌另填大小；非等比缩放后可重新悬停或点击「更新」校验。令牌尚在生成或加载资源时会延后重试。

贴花的局部 Y 坐标按「底面局部 Y − `BACK_STAMP_GAP`」计算。因此 `-0.09` 等于在底面局部 Y 的基础上加 `0.09`，沿令牌的局部 `+Y` 方向校准。

## 游戏内检查

1. 正面朝上时，确认令牌正面没有「済」印，面板为 `行動 未`。
2. 按 **F** 翻转一名武将，等待旋转结束，确认其背面有印章，面板为 `行動 済`。
3. 翻回正面，确认面板印章隐藏，令牌正面保持原图。
4. 连续点击「更新」，确认印章数量没有增加；若原有其他贴花，确认它们仍在。
5. 检查一枚 `role=unit` 普通部队，确认没有被贴印。
6. 若印章大小或方向不合适，先用一枚同类令牌调整；确认后再应用到同类武将。图片空白则检查统一 URL 和网络连接。
7. 确认效果后正常保存 TTS 游戏，保存令牌资料和贴花。

上述比例和偏移已经按你当前令牌的游戏内实测结果同步到默认设置。
