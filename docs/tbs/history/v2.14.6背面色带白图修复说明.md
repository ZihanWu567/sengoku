# v2.14.6：背面士气色带白图修复

背面的正常设计仍为琥珀／朱红色带；象牙白只用于背面数字。白色条并非新增的状态配色。

## 已确认的情况

- 用户确认正面色带正常，只有背面白色。
- 只读核对最新游戏存档，Global 与本地 v2.14.5 一致。
- 游戏图片缓存中的两张色带实际为琥珀、朱红，不是白图。
- 旧代码在满士气时把背面色带 Image 的图片设为空，受损后再切换到 URL。
- 检查已安装游戏的程序集：`XmlUIObject.OnTextureFinish` 将预载 Sprite 按资源名注册；`ImageAttribute.Apply` 遇到 URL 时可能启动独立 URL 下载路径，该路径并不由当前 `Object.UI.loading` 等待覆盖。

因此，即使 UI 预载已结束，旧代码仍可能在首次显示色带时使用尚未取得图片的 Image，露出白色矩形。持续白色的具体下载失败或时序问题尚未在游戏中现场复现。

## 本次修正

仅将背面色带绑定改为 `sgub_band_amber`／`sgub_band_red`，直接使用已登记的预载资源。首次创建即保留非空资源名；满士气时只隐藏，不清空图片。加载结束后和每次重新显示前，明确先绑定图片、再打开显示。

其余背面图片继续使用此前正常工作的绑定方式。没有改变正面贴花、位置、高度、数字颜色、按钮、兵种配置或云端地址。

## 安装

1. 打开 `Global_完整替换版_v2.14.6.txt`，在文件正文中全选复制。
2. TTS → Scripting → Global → Lua，全选替换旧代码。
3. Save & Play。
4. 以長柄足軽背面为例：士气 5 时无色带，4／3 时琥珀，2／1 时朱红，0 时敗走；回到 5 后隐藏，再扣到 4 应再次正常显示。

不需要重新上传图片，也不用调整 `-0.099`。本版包括此前添加的騎馬武士、徒歩武士和槍足軽。

本次验证覆盖资源登记、隐藏时保留图片绑定、首次扣减时先绑定后显示、阈值切换、恢复满士气和资源加载期间士气变化。模拟检查不替代 TTS 中的实际渲染确认。
