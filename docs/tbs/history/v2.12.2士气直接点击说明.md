# v2.12.2：直接点击士气数字

完整替换新版 `兵種与備隊面板合并版_日本漢字.lua` 到 Global，点击 Save & Play。

## 操作

- 鼠标指向右栏的士気数字，出现淡淡的金色亮区。
- 左键点数字：士気增加 1。
- 右键点数字：士気减少 1。
- 正背面各自修改当前那面的士气，不会触发翻面。
- 移動与兵数仍然只是显示。

点击面现在跟数字图片使用同一组三维坐标，仅向各面的外侧抬起 0.004 个局部单位，点击区域覆盖整张 176×176 的数字画布。原来点击面与贴图分别计算高度，背面的间距尤其明显；这一版去掉该差异。

刷新图片时，也同步更新点击面的位置和大小。平常没有按钮底色；悬停、按下时只有淡淡反馈，不显示遮挡棋面的提示文字。右键菜单仍可作为备用。

## 正反面的区分建议

推荐保留原有家族底色，另做一张所有家族共用的背面透明装饰图：

- 背面外框采用双线，正面保持单线。
- 背面右侧数值栏的边缘增加窄斜纹带，数字下面仍留干净底色。
- 若背面在规则中代表疲劳，可再加「疲弊」小印；名称应随你给背面定义的含义决定。

双线和斜纹都能留在叠放武将后露出的边缘，缩小视角时仍有区别，也不依赖家族的红、蓝、白、绿等底色。此方案可共用原来的八张数字 PNG。

这次仅修改士气点击操作，背面装饰是建议，尚未绘制或写入棋面。

## 验证范围

使用 TTS 自带 MoonSharp 检查脚本、数字与按钮的位置同步、按钮回调的左右键增减、正背面独立数值、长直链与既有武将面板功能。尚未在运行中的 TTS 内实测鼠标命中，安装后可用悬停亮区确认点击位置。
