## 上传文件

- `PNG/行動_正面_済.png`：透明背景、深墨色小箭头和朱红色「済」。

## 接入

1. 按已确认方案，在 PS 中去掉部队正面底图原有的大三角，保留纸纹和边框。
2. 将 PNG 文件夹中的两张素材上传到 TTS 云端，分别取得图片直链。
3. 在 Global 中搜索 `UNIT_ACTION_IMAGES`，只替换 `front_unacted` 和 `front_acted` 引号内的地址：前者对应「未」，后者对应「済」。不要改动背面的两个地址。
4. Save & Play 后，点击右上角检查未／済切换。画布尺寸和脚本点击范围未改变。

本地 Global 当前仍保留旧的正面云端地址，等待这两张新素材的上传直链。无需重新上传数字、阵旗或背面素材。
