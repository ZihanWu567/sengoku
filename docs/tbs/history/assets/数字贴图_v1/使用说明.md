# 数字贴图 0–7

PNG 文件夹内含八张 256 × 256 透明图片，与棋面使用同一字体 Source Han Serif JP Bold（思源宋体 JP 粗体）。字色为墨黑 #29251F，所有数字使用同一字号，保留字形原本宽度，不横向拉伸。

每张图片的可见字形居中；图片四周透明。将每张图的完整画布以 176 × 176 棋面像素显示时，数字实际墨迹高约 137 像素。该值以 1200 × 1200 棋面为基准；放大缩小时按比例缩放。

预览使用兵数 1、士气 6、移动 4；数字中心分别为 (1100,374.5)、(1100,748)、(1100,1081.5)。

上传时使用 PNG 文件夹内的原始图片，不要上传带棋盘格的预览截图。上传到 TTS 云端后，将八个图片直链按数字填入 Global 对应配置。

生成与检查：运行生成数字.cjs。字形尺寸与检查.json 记录每个数字的像素边界、透明像素和边缘裁切检查。字体与许可证沿用既有字体目录。
