## 在 TTS 中替换

将 PNG 文件夹中的 5 张 PNG 上传为新的云端图片，再只替换 Global 顶部以下 5 个地址：

| 配置 | 新素材 |
|---|---|
| UNIT_BACK_RAIL_IMAGE_URL | 背面右欄.png |
| UNIT_ACTION_IMAGES.front_unacted | 行動_正面_未.png |
| UNIT_ACTION_IMAGES.front_acted | 行動_正面_済.png |
| UNIT_ACTION_IMAGES.back_unacted | 行動_背面_未.png |
| UNIT_ACTION_IMAGES.back_acted | 行動_背面_済.png |

然后 Save & Play。保持 PNG 原画布大小，不要裁掉透明边或导出为 JPEG。布局坐标、比例、数字素材和阵旗无需修改。原有云端地址未被本次本地素材生成覆盖。

预览目录中的合成棋面只供对比，不要上传为这 5 张正式素材。预览的灰白棋盘格代表透明区域，正式 PNG 中没有棋盘格。

生成器会检查全部透明带的 alpha 为 0、其余像素与原素材一致，并核对合成后原家族外框逐像素保留。此检查不代替 TTS 内的镜头渲染检查；本次改动不涉及贴花高度与防闪烁配置。
