3. 在 TTS 的 Scripting → Global → Lua 中全选旧代码，用完整代码替换，然后 Save & Play。不要复制差异视图里的新旧两组行，不要追加到原脚本后面，无需修改 XML 页或各棋子的 Description。

图片尺寸和透明边缘需要保留，不要裁剪。今后若某个色带地址留空，只隐藏该档位色带，士气数字和点击逻辑继续工作。

## 显示规则

每一面单独比较该面的当前士气和 `UNIT_CONFIGS` 中的 `max_front` / `max_back`：

- 满值：无色带。
- 低于上限且高于一半：琥珀色。
- 大于零且不高于一半：朱红色。
- 士气为零，或部队处于「敗走」：无色带，由原有归零／敗走显示处理。

例：正面上限 6 时，5、4 为琥珀，3、2、1 为朱红。背面上限 5 时，4、3 为琥珀，2、1 为朱红。正面归零自动翻面后，背面恢复满值 5，因此不显示色带。加回满士气时也会立即移除。
