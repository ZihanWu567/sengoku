# 士气色带 v2：小圆角与轻渐变

制作日期：2026-10-18。

## 上传哪些文件

- `PNG/士気_琥珀.png`：士气受损、尚高于本面上限的一半。
- `PNG/士気_朱紅.png`：士气降至本面上限的一半或以下。

两张都是 1152 × 192 的透明 PNG，比例仍为 6:1。棋面上的显示尺寸继续使用现有的 144 × 24，不要改成图片的导出分辨率。

## 如何替换

1. 将这两张 PNG 上传至 TTS 可读取的图片空间，取得图片直链。
2. 在目前正常工作的 Global 脚本里搜索 `UNIT_MORALE_BAND_IMAGES`。
3. 仅将 `amber` 的地址换成新版琥珀直链，`red` 的地址换成新版朱红直链。
4. 地址保持在英文双引号内，使用直接的 `https://...` 地址，不要粘贴 Markdown 的 `[地址](地址)` 格式。
5. Save & Play 后，检查正反面士气减少时的显示。

不用替换整份 Global，也不用改位置、高度、色带宽高、士气规则或按钮。当前脚本与现有云端地址未被本次素材制作修改。

## 设计与预览

- 去掉旧版深色描边，改用小圆角和平滑边缘。
- 渐变仅沿上下方向轻微变化，整条保持同一种状态色；不是进度条。
- 除圆角抗锯齿边缘外，色带主体不透明；外围透明，无阴影或外发光。
- 正面仍是黑色数字，背面仍是象牙白数字，沿用现有区分方式。
- `新版色带预览.png` 是本地合成预览，包含旧版对比和正反面士气格。
- `缩小效果.png` 展示完整棋子缩至 150 和 100 像素时的效果。
- `SVG` 文件夹保留可编辑的矢量源文件；上传游戏使用 PNG。
