## 新版如何读取资料

武将姓名、生诞年、统率、画像和状态可以直接写入各自令牌的 Description。例如太田資正：

```text
team=ota_honjin
role=main
name=太田資正
birth=1522
command=5
image=
flag_image=
status=無傷
title=備大将
formation=太田家 本陣
order=防御
```

在 `image=` 后面填入完整的云端图片直链，不用引号，也不能使用本地文件路径。新增画像、改统率或改姓名时，无须修改 Global。其他十一人的完整模板请直接从新指南复制。

v2.9 可以在主将的 `flag_image=` 后填写本隊陣旗的完整直链，也可以使用字段别名 `陣旗=`；只填其中一种，副将不用填。留空、删除该行或写 `-` 会隐藏旗。真实地址的填写方法见[令牌資料填写指南](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/令牌資料填写指南.md)。

同一备队三人使用相同 `team`，角色分别为 `main`、`deputy1`、`deputy2`。新备队使用新的 `team` ID，并在主将填写 `formation`，不需要增加 Global 中的名单。

普通部队推荐直接添加英文所属标签：本陣用 `ota_honjin`，岩付衆用 `iwatsuke_shu`，江戸衆用 `edo_shu`，松山衆用 `matsuyama_shu`。在物件右键 **Tags** 中启用，不是在 Description 中写 `tag=`。所属标签优先于 Description 的 `team`，一枚棋子只启用一种所属标签，原有兵种等标签保留。旧的 `team` 加 `role=unit` 方式继续兼容。操作与地图旗显示见[地图陣旗与英文标签](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/地图陣旗与英文标签.md)。

## 显示和操作

面板基础尺寸为 `600 × 1000`，主将画像 `260 × 260`，两个副将画像各 `200 × 200`。副将继续左右并排，保留完整信息。姓名和年龄同一行，机动、状态和行动同一行。「統率」标题、彩色当前数字和六格圆圈整组居中；六格独立、等宽、等距排列，切换为 `X` 后位置不变。主将每格宽 `28`，圆圈字号 `30`、`X` 字号 `24`；副将每格宽 `24`，圆圈字号 `24`、`X` 字号 `20`。圆圈分别向上微调 `2` 和 `1` 像素。无选队时的提示为「請指向武將令牌」，关闭按钮为「關閉」；面板不使用假名。

有陣旗时，主将画像右侧显示 `90 × 240` 的旗，间距 `20`，画像和旗整体居中，旗纵向对齐画像中心；画像和「備大将」标题一起向左移 `55`，姓名及能力行仍按整卡居中。无旗时画像和标题回到中央。面板高度不增加，副将显示不变。旗保持原图颜色，不跟随伤势暗化，不叠加负伤角标或「済」印，也不弹出悬停提示。

本版附有[太田家三紋陣旗 PNG](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/素材/太田家_三紋陣旗_v1.png)，白底三枚家纹纵列、无文字，尺寸 `768 × 2048`，比例为 `3:8`；预览已使用这张素材。这是依据你原有家纹制作的游戏美术设计，并非考证复原。图片尚未上传到云端；按[新陣旗使用说明](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/新陣旗使用说明.md)上传后，将所得直链填在主将的 `flag_image=` 后。

- 年龄按 `1563 - birth` 计算。修改武将的 `birth` 即可更正年龄；若剧本年份改变，再统一修改脚本的 `CURRENT_YEAR`。
- `status=無傷` 显示绿色、机动 `9`；`status=浅手` 显示浅红色、机动 `4`，統率保持原值；`status=深手` 显示深红色、机动 `4`，統率数字减 `1`，最后一个原始实心圆直接替换为 `X`，例如基礎統率 `5` 的圈条为 `●●●●X○`；`status=討死` 显示統率数字 `X`、圈条 `XXXXXX` 和机动 `—`，画像与卡片进一步压暗。深手时原始統率 `1` 可以显示为 `0`，圈条为 `X○○○○○`。失效格不叠加圆圈，`command` 字段仍填写原始 `1`～`6`，恢复無傷后自动恢复原值。
- 固定标签「状態」无底色，点击其右侧带底色的状态值，按「無傷 → 浅手 → 深手 → 討死 → 無傷」切换并写回 Description。状态标签、按钮和文字不弹出悬停提示，姓名的资料错误提示继续保留。旧值 `健康`、`軽傷`、`重傷`、`陣没` 仍兼容，显示和点击后的写回使用新名称。所有玩家都可以切换；十二种座位颜色的选队和面板控制独立，状态与命令共享，Grey 旁观者共用 Grey 面板。
- 令牌正面朝上显示行动 `未`，翻面显示 `済`，三名武将分别记录。面板画像右下角和桌上令牌背面统一使用同一张「済」图片；印章地址已在 Global 设置，无需逐枚填 `acted_image`。旧 `acted_image` 字段保留也无影响，v2.9 会忽略它，画像 `image=` 仍单独读取。
- `攻撃`、`防御`、`機動`、`再編` 按钮将命令写入主将令牌的 `order`。这些按钮记录命令，不自动执行改令检定或传令延迟。
- 最下排最左侧的 `本隊陣旗：無`／`本隊陣旗：有` 切换当前備隊的地图小旗；有效主将的长旗平时常驻，悬停某枚棋子会展开该枚的长旗并高亮本隊。无可用主将 `flag_image` 时旗开关禁用，同隊高亮仍可用。全隊旗按座位颜色独立控制；轮廓高亮是共享桌面效果，多人查看不同隊时可能同时出现多隊高亮。
- `固定：無`／`固定：有` 用来切换是否固定当前备队；`更新` 重新扫描令牌和所属标签；`縮小`、`拡大` 调整面板尺寸；`關閉` 收起面板、解除固定并清除当前座位临时的地图显示，再悬停令牌可重新打开。主将常驻旗保留。未固定时换隊会收起原隊全隊旗；固定时旗开关作用于固定隊，悬停效果跟随鼠标实际指向的棋子。

討死画像使用深灰色乘色处理进行暗化；这不会将原图真正转换为黑白，原有颜色可能仍可见。需要完全黑白时，另用黑白画像素材。

令牌背面印章使用贴花叠加，保留原底图和其他贴花。自动处理 `main`、`deputy1`、`deputy2` 武将，普通 `role=unit` 不贴；重复刷新会去重。当前默认采用你对现用令牌的实测参数：`BACK_STAMP_RATIO=1`，印章直径为平面较短边的 100%；`BACK_STAMP_GAP=-0.09`，用于局部位置校准。安装和检查见[令牌背面済印](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/令牌背面済印.md)。

已显示且已经建立索引的三名武将约每 `0.75` 秒刷新资料。新增令牌、改变队伍或角色后，点击 `更新`。同队同角色出现多枚令牌时，需要纠正重复配置。

当前版本的稳定定时刷新不再重复测量背面贴花尺寸或读取贴花；加载、新建令牌、悬停、放下或点击「更新」时仍会校验贴花。非等比缩放令牌或手动改过贴花后，重新悬停或点击「更新」即可校验。画像与陣旗等本脚本 Global UI 自定义资源登记最多保留 `64` 份当前及近期资源，同时保留其他脚本资源；这不表示直链图片已缓存，也没有实测帧率提升结论。合并版还增加了对异常旧存档资料的容错处理。

地图旗的 Object UI 尺寸、轴向及多人效果仍需实机确认；脚本会保留现有 Object UI 的节点和资源，但初次挂载／清理时重新提交 XML 可能重置第三方可拖动界面的位置。地图旗的尺寸参数和兼容范围见[地图陣旗与英文标签](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/地图陣旗与英文标签.md)。

画像是否能显示还取决于链接和网络；填入网址不代表远端图片一定可读取。姓名上的悬停提示可以帮助检查不合法数字或画像地址等资料。

武将资料保存在 Description 中，随游戏保存；面板缩放不写入存档。填写完成后请正常保存 TTS 游戏。
