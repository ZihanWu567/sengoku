# v2.13.3：单独增加背面底栏与图案的间距

本版基于 2026-10-16 用户粘贴的当前 Global，沿用所有 22 个云端地址，其中包括刚上传的 5 张透明外框素材。

用户提供的 `UNIT_SURFACE_CLEARANCE` 与 `UNIT_OVERLAY_SEPARATION` 均为 `0.001`。背栏和图案并非完全共面，而是仅相差 `0.001` 个物件局部单位。

修正后的配置：

```lua
UNIT_DEFEAT_FRONT_GAP = -0.01
UNIT_DEFEAT_BACK_GAP = -0.099
UNIT_SURFACE_CLEARANCE = 0.001
UNIT_OVERLAY_SEPARATION = 0.01
```

`UNIT_OVERLAY_SEPARATION` 现在只控制背面数字和背面未／済。正面未／済单独保留原有 `front_action_lift = 0.001`，避免跟随背面调整。

以各面的校准平面为起点，向外的局部距离为：

| 元素 | 原版 | 修正版 |
|---|---:|---:|
| 正面数字 | 0.001 | 0.001 |
| 正面未／済 | 0.002 | 0.002 |
| 背面底栏 | 0.001 | 0.001 |
| 背面三项数字 | 0.002 | 0.011 |
| 背面未／済 | 0.002 | 0.011 |

背面朝外是局部 Y 减小，所以背面上层图案的 Y 比底栏小 `0.01`。数字和未／済位于不同格子，彼此不重叠，可以共用同一层。可点击区域始终在对应图案外侧再隔 `0.004`，随图案一起移动。

安装：全文复制「兵種与備隊面板合并版_日本漢字.lua」到 TTS 的 Global，点击 Save & Play。无需再次上传图片。部队士气、行动状态、阵旗造型以及武将面板规则不作更改。

验证结果：合并 Global 的 2664 项行为检查通过，两份独立面板各 1168 项通过；XML、按钮回调、ID 及事件入口检查通过。覆盖正面高度保持、背面层序、点击跟随及非等比缩放。

验证边界：脚本检查可以验证前后层序、点击区域跟随、翻面及保存等行为；无法替代 TTS 内的显卡渲染。安装后重点观察背面数字与未／済在常用推演距离、斜视及缩远时的显示。
