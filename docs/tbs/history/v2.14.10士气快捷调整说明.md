# v2.14.10：同一个士气数字快速补满／清空

使用 `Global_完整替换版_v2.14.10.txt` 完整替换 Global Lua，然后 Save & Play。本版沿用现有图片直链、正反面显示位置和士气色带，不需要重新上传素材。

## 首次设置

每位玩家打开 **Options → Game Keys**，找到 **士気快捷調整**，点击第一键位栏后按一下 **左 Ctrl**。如果希望右 Ctrl 也能使用，可把第二键位栏绑定为右 Ctrl。每位玩家设置一次即可；只要脚本保持这个标签，重新加载存档仍会沿用绑定。

已检查本机安装版本的按键代码：左右 Ctrl 都在可扫描的绑定范围内，且没有被列为禁止绑定键；尚未在游戏界面完成实际绑定和组合点击验证。自定义快捷键不会屏蔽游戏原有键位功能，如果使用中与原有操作冲突，可改绑一个未占用的键。需要先设置绑定，不能直接按 Ctrl 即生效。

## 操作

鼠标始终点击原来的士气数字，不增加「尽／満」按钮。

| 操作 | 结果 |
|---|---|
| 左键 | 当前面士气 ＋1 |
| 右键 | 当前面士气 −1 |
| 按住绑定键＋左键 | 补满当前面，并解除敗走 |
| 按住绑定键＋右键 | 清空当前面 |

松开快捷键即恢复普通加减。所有玩家都可操作，某位玩家按住快捷键不会改变其他玩家点击数字的含义。

正面从正数清空到 0：自动翻到背面，并将背面设为该兵种的满士气。以長柄足軽为例，正面清空后显示背面 5。

背面清空到 0：进入敗走。此时按住快捷键＋左键，会补满背面并解除敗走，不自动翻回正面。「未／済」始终保留。

若玩家把背面士气已经归零的敗走棋子手动翻回正面，再快捷补满正面，则同时恢复已归零的背面储备，以解除由背面 0 触发的敗走。另一面士气尚未归零时保留原值。

翻面后的 0.5 秒内忽略正反面士气连点，避免一次操作耗尽两个阶段。加载存档、换座或玩家离开时清除临时按键状态；换座后如需快捷调整，应松开并重新按住绑定键。
