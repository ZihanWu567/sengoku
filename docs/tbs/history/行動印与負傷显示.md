# 行動印与負傷显示

更新：2026-10-10。v2.9 面板分别记录行动与负伤：令牌翻面表示该武将已经行动，面板状态按钮或 Description 中的 `status` 表示無傷、浅手、深手或討死。行動印现在统一设置，面板与桌上令牌背面使用同一张「済」图。

## 安装

使用[兵種与備隊面板合并版_日本漢字.lua](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/兵種与備隊面板合并版_日本漢字.lua)完整替换 TTS 的 Global Lua，然后点 **Save & Play**。如果你后来又改过其他 Global 功能，先按[与现有 Global 合并方法](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/与现有Global合并方法.md)保留那些改动。不要把新版代码重复追加到旧代码末尾。

## 统一「済」印章

Global 已统一设置你提供的[済印图片](https://steamusercontent-a.akamaihd.net/ugc/16127482967476073358/AB4E3857AE6ECD0830ECE8C32682AE244709D8B5/)。安装 v2.9 后即可使用，不必再次上传或逐枚填写印章地址。

统一 URL：

```text
https://steamusercontent-a.akamaihd.net/ugc/16127482967476073358/AB4E3857AE6ECD0830ECE8C32682AE244709D8B5/
```

Description 中的旧 `acted_image` 字段可以删除，也可以保留；v2.9 不读取它，旧地址和 `-` 都不会覆盖统一印章。各武将 `image=` 的画像地址继续独立读取。

令牌正面朝上显示 `行動 未`；令牌翻面后显示 `行動 済`，并在面板画像右下角显示统一印章。翻回正面后面板印章隐藏。每名武将的翻面状态独立保存，三人可以分别处于未行动或已行动。

## 桌上令牌的背面

脚本也会为 `main`、`deputy1`、`deputy2` 武将令牌添加同图背面贴花，普通 `role=unit` 不贴。贴花保留令牌原有底图和其他贴花，并去除本功能生成的重复印章。背面贴花固定留在反面；翻回正面后被令牌遮住，不用每次翻面重新生成。

加载、新建令牌、悬停、放下令牌和点击「更新」时会检查贴花。当前采用你对现用令牌的实测参数：印章放在背面中央，直径按平面较短边的 100% 计算，局部偏移校准值为 `-0.09`。贴花不会自动把令牌背面底图换成面板画像，底图需在物件的自定义设置中准备好。完整操作见[令牌背面済印](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/令牌背面済印.md)。

稳定的定时资料刷新不再重复读取令牌贴花和尺寸。非等比缩放令牌或手动改过贴花后，重新悬停或点击「更新」进行校验；面板资料的自动刷新继续照常运行。

## 受伤效果

点击面板中该武将「状態」右侧带底色的状态值，即可循环切换，不必手动编辑 Description。循环顺序为「無傷 → 浅手 → 深手 → 討死 → 無傷」。「状態」固定显示，不带底色；只有右侧值的文字和底色改变。状态标签、按钮和文字均不弹出悬停提示，姓名的资料错误提示仍保留。所有玩家都可以写回令牌，不需要房主或管理员身份；正在查看同队的面板会同步刷新。十二种座位颜色的选队、固定、关闭和缩放独立，Grey 旁观者共用 Grey 面板。

如果仍需手动设置，在相应武将的 Description 写入：

```text
status=浅手
```

浅手会使用浅红外框和浅红 `浅手` 角标；只把機動降为 `4`，統率数字和六格保持原样。深手使用深红外框、深红 `深手` 角标，把画像略微压暗，并将当前統率数字减 `1`，同时把六格最后一个原始实心圆直接替换成 `X`。失效格只显示 `X`，不在圆圈上叠加叉号：

```text
status=深手
```

恢复無傷：

```text
status=無傷
```

这会恢复绿色状态文字、普通外框、原始統率和机动 `9`，失效格的 `X` 恢复为实心圆。浅手和深手的机动均为 `4`。例如基礎統率 `5` 的深手数字显示 `4`，圈条为 `●●●●X○`；基礎統率 `2` 的深手数字显示 `1`，圈条为 `●X○○○○`；基礎統率 `1` 的深手数字显示 `0`，圈条为 `X○○○○○`；基礎統率 `6` 的深手数字显示 `5`，圈条为 `●●●●●X`。Description 的 `command` 始终保存原始 `1`～`6`，不用手动扣减，也不额外增加有效統率栏。

「統率」标题、数字和六格合为一组居中，六格各自占固定等宽位置，状态切换不改变间距。主将每格宽 `28`，圆圈字号 `30`、`X` 字号 `24`；副将每格宽 `24`，圆圈字号 `24`、`X` 字号 `20`。圆圈向上微调，主将 `2` 像素、副将 `1` 像素，使它们与数字更齐整。

设置討死：

```text
status=討死
```

討死时統率数字显示 `X`、机动显示 `—`，六格显示 `XXXXXX`。画像用深灰色调制进一步压暗，卡片、姓名和能力文字也会变暗。图片处理是对原图的乘色暗化，不能真正将彩色原图转换为黑白；若要完全黑白，需要另外准备黑白画像素材。受伤角标在画像左上，`済` 印章在画像右下，两者可以同时显示。

v2.9 的本隊陣旗单独显示在主将画像右侧；主将 Description 使用 `flag_image=` 或 `陣旗=` 设置。旗不叠加伤势角标或「済」印，也不随受伤／討死暗化，始终保持原图颜色。旗的隐藏与显示不改变行动状态、负伤状态或面板高度；填写空值或 `-` 隐藏旗后，主将画像回到中央。地图旗共用这一地址，操作见[地图陣旗与英文标签](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/地图陣旗与英文标签.md)。完整填写方法见[令牌資料填写指南](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/令牌資料填写指南.md)。

旧描述里的 `健康`、`軽傷`、`重傷`、`陣没` 仍能识别，面板统一显示为新名称；点击切换后，保存的 `status` 会使用無傷、浅手、深手或討死。

## 最小检查

1. 安装 v2.9 后，不填写 `acted_image`，确认三名武将的面板都能显示统一印章。
2. 翻转其中一名武将，确认只有该人的画像出现 `済` 印章。
3. 翻回正面，确认印章消失。
4. 点击「状態」右侧的状态值，依次检查 `浅手`、`深手`、`討死` 和 `無傷`；固定标签不变，右侧值的文字和底色随状态改变。
5. 确认浅手的統率数字和圈条没有变化，深手的数字减 `1`、最后一个原始实心圆直接替换为 `X`；討死数字显示 `X`、圈条为 `XXXXXX`，整体进一步压暗；恢复無傷后显示原始統率，暗化消失，失效格恢复实心圆。
6. 同时把该武将翻面，确认受伤效果和 `済` 印章同时存在。
7. 确认桌上武将令牌只有背面带印章，反复点「更新」没有新增重复贴花，普通部队没有被贴印章。
8. 确认統率整组居中、六格等距，状态标签及状态值没有悬停提示；姓名的资料错误提示继续保留。

图片实际能否加载仍取决于 TTS Cloud URL 和网络连接；脚本会检查 URL 是否以 `http://` 或 `https://` 开头，但不会替远端图片做可达性保证。
