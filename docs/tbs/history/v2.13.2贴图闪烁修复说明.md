# v2.13.2 棋面贴图闪烁修复

截图里阵旗随角度出现横条，与贴图和棋面近乎共面的深度冲突相符。只读检查最新 TS_AutoSave.json 的 25 枚部队，没有发现重复的部队贴花或残留的旧阵旗 UI。

本版沿用最新游戏存档中的部队校准值：正面 -0.01、背面 -0.09（此前记录是 -0.099）。武将背面済印的 BACK_STAMP_GAP 仍为 -0.099。22 个云端图片地址和敗走宽高比 1 已保留。

在校准面之外新增独立的显示间距：

```lua
UNIT_SURFACE_CLEARANCE = 0.01
UNIT_OVERLAY_SEPARATION = 0.01
```

- 最底层图片（阵旗、正面数字、敗走、背面深色栏）从校准面向外移动 0.01。
- 背面数字和正反面的未／済再向外移动 0.01，避免与下层画面重合。
- 点击面继续在对应图片外侧 0.004；右侧坐标、旋转、士气规则不变。
- 正面向局部 +Y、背面向局部 -Y；以上是物件局部单位，随 Y 缩放，不是固定世界距离。
- 继续按已有贴花名称更新，保留其他模块的贴花；无需重新上传图片。

安装：将「兵種与備隊面板合并版_日本漢字.lua」全文替换到 TTS 的 Global，再 Save & Play。此操作没有直接修改游戏存档。

验证结果：合并版 2650 项行为检查通过，独立面板两份各 1168 项通过；XML、按钮回调、ID 与事件入口检查通过。

验证边界：Lua 行为测试不包含显卡渲染。仍需在游戏内以近距离、正常推演距离和拉远视角，分别检查正反面及倾斜观察。如果仍有横条，可仅将 UNIT_SURFACE_CLEARANCE 从 0.01 小幅增加到 0.02；若只有深色栏上的数字闪烁，再调整 UNIT_OVERLAY_SEPARATION。不要重新调整已校准的正背 GAP 或旋转。较大间距可能在极低视角看出悬浮，不宜无限增加。

阵旗造型本次未更换。建议采用带左侧竖杆、上横杆及简洁系环的长旗轮廓，单个较大的上部家纹，浅色布面与克制的褶皱。具体家纹、数量和排列须与对应家族资料分开核对；这属于拟古设计建议，不能直接当作太田資正实旗的复原结论。
