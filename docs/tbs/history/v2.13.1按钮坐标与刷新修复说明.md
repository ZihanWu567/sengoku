# v2.13.1：右侧点击与数字刷新修复

日期：2026-10-15

## 使用

将 `兵種与備隊面板合并版_日本漢字.lua` 全文替换到 TTS Global，点击 Save & Play。
沿用 v2.13 的全部素材、标签、Description 和士气规则，无需重新制作或上传图片。
如果在游戏里另外修改过图片直链，请保留到新版顶部的对应配置中。

- 士気数字：左键＋1，右键－1，点击区域位于右侧对应数字上。
- 右上角：点击切换「未／済」，正反面共享行动记录。
- 正面由正数减到 0：自动翻面，长柄足轻背面设为 5。
- 背面减到 0：显示「敗走」。翻面不会改变「未／済」。

## 已修正

### 按钮在左、图片在右

对照本机 TTS 程序集确认：经典按钮 API 的位置经过 LuaPanel 转换后，实际物件局部位置为 `(-x,y,z)`；贴花直接使用局部位置。旧版将两者的参数直接设成一样，导致左右相反。

新版将按钮完整 X 坐标取反，含模型中心偏移；Y 和 Z 维持已校准的位置。士气、行动和文字后备一并修正。按钮旋转也改为与实际贴图方向匹配，避免备用文字倒置。

### 数字切换时重新读图

TTS 的 setDecals 会重建该对象贴花。图片按 URL 缓存；当某个数字在全桌不再使用时，它的纹理引用可能被清理，下次显示又需要读取。

新版在开局预载一套固定素材并保留引用：正背数字各 8 张、行动角 4 张、背面栏和敗走图各 1 张，最多 22 个唯一 URL。预载使用桌面远下方的微小全局贴花，不生成实体棋子；全桌共用一份，数量不随部队数或点击次数增长。重复 URL 只保留一份，只有图片配置改变时才重新设置。

首次进入游戏仍需等素材载入，远程图片速度取决于连接和地址是否有效。载入完成后，切换到其他数值可以直接复用缓存。数值与图片更新在同一次点击回调中提交，没有增加延迟刷新计时器。

## 代码整理

- 正背面士气增减共用一个处理函数；到达上限／下限后继续点击不重复提交显示。
- 部队贴花、清理与预载共用差异比较逻辑，保留其他脚本和用户贴花。
- 批量生成、销毁、放下棋子时，面板刷新合并到一帧；武将状态／命令点击仍即时处理。
- 陣旗按钮每轮只写最终可用状态，取消先禁用再启用的反复更新。
- 更新画像资源时读取最新的第三方资源，避免覆盖其他脚本后来加入的内容。
- 保留既有外部回调、旧存档兼容、表面高度校准和按座席显示。
