# v2.14.5：新增三种兵种

| 兵种 | 棋子标签 | 正面 士气／移动 | 背面 士气／移动 |
|---|---|---|---|
| 騎馬武士 | `unit_kiba_samurai` | 8／6 | 7／5 |
| 徒歩武士 | `unit_kachi_samurai` | 8／4 | 7／3 |
| 槍足軽 | `unit_yari_ashigaru` | 5／4 | 4／3 |
| 長柄足軽（原有） | `unit_nagaye_ashigaru` | 6／4 | 5／3 |

这里的「槍足軽」对应此次新增的持枪足轻，与三间长枪使用的「長柄足軽」分开。

## 安装

仅更新兵种配置：打开 `兵種配置_四兵種_v2.14.5.txt`，将其中整段 `UNIT_CONFIGS = { ... }` 替换 Global 原有的完整 `UNIT_CONFIGS` 表。不要追加第二份表，也不要粘贴进图片地址表。这种方法保留你在游戏中另行修改过的图片直链。

完整更新：打开 `Global_完整替换版_v2.14.5.txt`，在文件正文中全选复制，再到 TTS 的 Scripting → Global → Lua 全选替换。此文件与当前合并版 Lua 字节一致；不要复制差异视图。

两种安装方法任选一种，完成后 Save & Play。

## 为棋子设置标签

每枚棋子只保留一种兵种标签。例如，把一枚長柄足軽改为騎馬武士时，移除 `unit_nagaye_ashigaru`，添加 `unit_kiba_samurai`。如果同时有两种兵种标签，脚本会使用配置表中先匹配的一种。

兵数仍用 `count_100`、`count_200`、`count_300`、`count_400`；无数量标签时默认显示 1。所属備隊标签照常填写。无需在 Description 写兵种数值。

新增且尚未保存部队状态的棋子会从正反面满士气开始。已经有保存状态的棋子更换标签时，会保留当前士气并限制到新上限；如果你要改成一支全新的满员部队，正反面分别左键点击士气数字补满即可。

## 自动转段

- 騎馬武士、徒歩武士：正面士气由 1 降到 0 时自动翻面，背面士气设为 7。
- 槍足軽：正面士气由 1 降到 0 时自动翻面，背面士气设为 4。
- 背面士气降到 0 时进入「敗走」。
