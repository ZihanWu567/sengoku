# v2.12.1 方向与双面阵旗修正

完整替换 `兵種与備隊面板合并版_日本漢字.lua` 到 TTS Global，然后 Save & Play。

本次依据两张实机截图修正：

- 正反面的数字、陣旗、敗走图案各自旋转 180°。
- 两面都修正左右坐标，数字归到右侧栏，阵旗位于该栏左侧的棋面内。
- 兵数、士気、移動仍按原有顺序从上到下排列，不颠倒整套布局。
- 士气点击区同步移动，左键加、右键减和右键备用菜单继续有效。
- 部队阵旗始终生成正面、背面两枚。每次刷新读取当前模型边界，修正先前仅按缩放缓存高度、加载后可能沿用早期边界的问题。内容没有变化时不重复写回贴花。

保留你已经实测的 `UNIT_DEFEAT_FRONT_GAP = -0.01`、`UNIT_DEFEAT_BACK_GAP = -0.099`，以及将领背面「済」的 `BACK_STAMP_GAP = -0.099`。八张数字 PNG 不需要修改或重新上传。

目前主脚本的数字图片仍使用本机文件地址。若你在 TTS 中另行填写过云端数字地址，请保留顶部 `UNIT_NUMBER_IMAGES` 的八个地址，再换入新版。

阵旗使用所属備隊主将的 `flag_image=`，不按棋子的正背面切换图片。读取本机最近的相关存档时，截图中江户众 200 人棋子实际带有 `ota_honjin` 标签，太田資正也已填写旗图地址；因此此次没有给它改名或改归属。

两面仍需在 TTS 中核对最终渲染。代码检查能验证坐标、两面贴花和状态更新，但不能代替实际模型上的可见性检查。旗缓存确实可能过期；现有存档未记录实际贴花位置，不能据此断言旧缓存就是此前正面缺旗的唯一原因。
