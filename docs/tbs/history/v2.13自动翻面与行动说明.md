# v2.13：部队自动翻面、未／済、深色背面数值栏

「済」就是已行动。部队翻面表示进入第二阶段，和行动状态分别记录。

## 安装

1. 打开同目录 `兵種与備隊面板合并版_日本漢字.lua`，全文替换 TTS 的 Global Lua，点击 Save & Play。
2. 如果上一版已填写了云端图片地址，请将原来的 `UNIT_NUMBER_IMAGES` 和 `UNIT_DEFEAT_IMAGE_URL` 保留到新版配置。阵旗仍读取已有武将描述。
3. 新素材已保存在 `部隊操作素材_v2.13/PNG`，脚本默认指向本机文件，可先本机试用。无需另改部队棋子的正反面原图。
4. 联机时上传这次的 13 张 PNG，替换脚本顶部对应地址；其他玩家不能读取你的本机路径。

| Global 配置 | 对应素材 | 数量 |
|---|---|---:|
| `UNIT_NUMBER_BACK_IMAGES[0]`～`[7]` | `数字_背面/0.png`～`7.png` | 8 |
| `UNIT_BACK_RAIL_IMAGE_URL` | `背面右欄.png` | 1 |
| `UNIT_ACTION_IMAGES.front_unacted` | `行動_正面_未.png` | 1 |
| `UNIT_ACTION_IMAGES.front_acted` | `行動_正面_済.png` | 1 |
| `UNIT_ACTION_IMAGES.back_unacted` | `行動_背面_未.png` | 1 |
| `UNIT_ACTION_IMAGES.back_acted` | `行動_背面_済.png` | 1 |

`正背面与远景预览.png` 含示例数字，仅供查看，不要作为棋面或贴图导入。`背面底图_十色_无数字` 是可选静态素材，这版脚本不需要它们。

## 操作

| 操作 | 结果 |
|---|---|
| 左键点击士気数字 | 当前面的士气＋1，不超过兵种上限 |
| 右键点击士気数字 | 当前面的士气－1 |
| 正面士气由正数减到 0 | 自动翻到背面，并将背面士气补到该兵种背面上限；长柄足轻为 5 |
| 背面士气减到 0 | 自动显示「敗走」 |
| 点击右上角 | 在「未／済」间切换；保留上方小朝向箭头 |

- 正反面共享一个行动记录：正面是「済」，翻到背面仍是「済」。每回合可再次点击右上角手动改回「未」。没有自动回合重置。
- 所有玩家都可操作，其他玩家看到同一状态。点击没有悬停提示文字。
- 翻面只由本次正面减值跨到 0 触发。重复点击正面 0、刷新及读档不会再次补满背面。
- 翻面过程中短暂忽略正面点击，避免快速连点重复转段。
- 不添加部队自定义右键菜单。兵数和移动力只显示；背面的移动力使用该兵种背面配置，长柄足轻为 3。
- 误减至败走后，可以在背面左键＋1校正；同时清除旧版手动敗走标记。这是数值修正操作，不代替规则中的恢复条件。

## 存档与外观

- 没有旧记录的新棋子从满士气开始，长柄足轻为正面 6、背面 5，行动为「未」。
- 旧棋子的士气原样保留，含 0；安装时不自动翻面或重置战局。旧记录若背面已为 0，原有「敗走」仍保留，可直接调整背面数字校正。
- 行动状态随 Global 存档保存。
- 背面右侧整条数值栏采用炭灰底、象牙白字与数字。家族背景、部队立绘、标题、阵旗继续使用现有素材。
- 右栏底板、数字、行动角采用分层贴花。正反面原有表面偏移 `-0.01 / -0.099` 保留；数字／行动角在底板外侧仅增加 `0.001` 个局部单位，透明点击面再外移 `0.004`。
