## 1. 安装新版布局

先另存当前 TTS 游戏，再打开上面的完整 Global Lua，复制全部内容，完整替换 **Scripting → Lua → Global** 中的代码，点击 **Save & Play**。不要追加到旧代码末尾。如果后来在游戏内修改过其他 Global 功能，先按[合并方法](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/与现有Global合并方法.md)保留那些改动。

## 2. 上传陣旗并取得直链

这张图片目前只在本地，尚未上传或接入实际 TTS。

1. 在 TTS 顶部打开 **Upload → Cloud Manager**。
2. 点击搜索框左侧的文件夹按钮，选择上面的 `太田家_三紋陣旗_v1.png` 上传。
3. 上传完成后，点击 Cloud Manager 中对应图片，将其 URL 复制到剪贴板。这是 TTS 官方说明的[上传与复制地址方法](https://kb.tabletopsimulator.com/custom-content/cloud-manager/)。

## 3. 填入太田資正的 Description

找到 `team=ota_honjin`、`role=main` 的太田資正令牌，在 Description 中保留原有资料，新增或修改这一行：

```text
flag_image=
```

把刚复制的完整 URL 粘贴到等号后，不加引号、不换行。不要填 `C:\...` 本地路径，也不要填图片所在网页的链接；必须是云端图片本身的直链。字段名也可以使用 `陣旗=`，二选一即可。副将不需要填写。

点击面板「更新」，或等待已显示队伍的资料自动刷新。确认陣旗加载后，保存 TTS 游戏。单纯安装脚本不会自动上传图片或代填地址。

## 布局与检查

主将画像保留 `260 × 260`，右侧陣旗改为 `90 × 240`，两者间隔 `20`，中心同高、整组水平居中。三枚家纹因此比旧 `60 × 160` 旗位更容易辨认，旗仍略低于画像高度。

「備大将」标题与画像一起向左移 `55`，标题框宽 `266`；姓名、年龄和能力行继续按整张主将卡居中。两名副将仍各为 `200 × 200`，面板仍为 `600 × 1000`，高度不增加。

把 `flag_image` 留空、删除或填 `-`，旗会隐藏，画像与标题同时回到中央。旗不随伤势暗化，不叠加伤势角标或「済」印。背面印章参数仍为 `BACK_STAMP_RATIO=1`、`BACK_STAMP_GAP=-0.09`。

若旗显示不出来，先检查 URL 是否完整，是否来自正确图片，能否直接打开图片；再确认该行填在主将而非副将上。进一步的 Description 模板和排查方法见[令牌資料填写指南](C:/Users/HP/Documents/ChatGPT/日本战国/TTS武将面板/令牌資料填写指南.md)。
