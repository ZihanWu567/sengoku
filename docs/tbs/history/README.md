# 历史资料：不是当前安装指南

本目录保留原本地工程的既有文本，便于追溯；正文原则上原样导入，来源与SHA256见上一级 `import-sources.json`。

旧文件可能包含旧版本安装入口、个人机器绝对路径、没有导入的本地图片链接，以及后来被取代的规则／UI。不要依照旧说明覆盖当前Global。

当前入口是仓库根README、`docs/HANDOFF.md`、`docs/tbs/CONFIGURATION.md`和 `tts/Global.lua`。

特别注意：

- v2.9／v2.10资料里的部队悬停展开旗，后来改成棋面内双面常显贴花；非部队物件的旗行为另论。
- 旧背面多层贴花、原生色带和资源传参修复过程已由v2.14.11当前Object.UI实现取代。
- 旧`-0.09`、`-0.099`和层间距的实验记录不能拿来覆盖用户最终确认的配置。
- v2.14.10原说明写Ctrl操作尚未实测；用户后来反馈成功，参见当前交接记录。
- “十色”制作文档对应较早资产；GitHub当前使用十二兵种×八色96张成品。
- diagnostics只收第一方问题分析摘要，没有TTS反编译IL正文、游戏DLL或运行态转储。
- assets子目录只归档制作说明／参数，不复制旧成品PNG，也不意味着所有历史图片链接在仓库可打开。
