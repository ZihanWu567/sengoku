## 安装这一枚長柄足軽
1. 保存当前 TTS 游戏；可以复制这枚棋子先试。
2. 在 TTS Cloud Manager 上传上述底图，取得图片 URL。右键该棋子打开 Custom，将对应的正面贴图换成这个 URL；若物件提供单独背面贴图槽，背面也使用同一底图。新底图是完整方形图片。Cloud Manager 上传操作见 [TTS 官方说明](https://kb.tabletopsimulator.com/custom-content/cloud-manager/)。
3. 在这枚棋子的 Tags 中启用以下标签，保留其余需要的标签：
   - `unit_nagaye_ashigaru`：長柄足軽，沿用现有兵种配置。
   - `count_100`：100 人。需要 200、300、400 人时改用对应 `count_200`、`count_300`、`count_400`，同一枚只选一个数量标签。
   - `ota_honjin`：太田家 本陣的所属标签。若属于其他備隊，保留那一隊原本的所属标签。
   - **`unit_ui_v2`：启用这次的新布局。**
4. 用新版完整 Global 文件替换 Scripting → Lua → Global 的全部内容，然后 Save & Play。不要在旧代码底部追加。
5. 检查顶部为「長柄足軽　100人」，底部为「士気」「移動」。无傷等武将面板和地图阵旗沿用原规则；普通部队描述不需要新增图片字段。
6. 保存游戏。以后更换兵种、数量或样式标签后，再 Save & Play 重建本组经典按钮；面板的「更新」主要刷新武将与所属资料，不代替此步骤。

没有 `unit_ui_v2` 的棋子继续使用旧排布。换回原底图并移除这个标签，再 Save & Play，即可恢复旧棋面。原版 Global 已保存在 `修复前备份/兵種与備隊面板_v2.9.1_部隊新布局前.lua`。

## 操作
- 士気：左键加 1、右键减 1，正反面数值分别保存；保持原来的正面上限 6、背面上限 5。
- 移動：正面 4、背面 3，只读，不设置额外增减按钮。
- 人数：同一底图能显示 100～400 人，不必为每个人数重新制作图片。
- 右键棋子 → **敗走表示切替**：原来的手动显示切换移到这里，牌面不再出现「切替」小按钮。该项使用 TTS 的 [自定义右键菜单接口](https://api.tabletopsimulator.com/object/#addcontextmenuitem)，不清除其他脚本的菜单。
- 原自动敗走逻辑仍是背面士気为 0 时显示「敗走」。手动开关不会覆盖这个自动条件。
- 已有棋子的士気继续从存档读取。预览中的 6／4、5／3 是示意数值；新棋子原本初始化为 0 的逻辑没有变。

## 显示与校准
兵种、人数共用顶部墨绿横栏；脚本使用白色名称、浅金人数。下面两个数字同大、同基线，士気为墨绿，移動为深墨色。背面数值为暗红。数值按钮透明，底图的细分隔线直接承担分区；不再出现两颗突出的白色方块。

底图参考原人物和武器姿势重绘，不是原画的无损放大，也不作为历史服饰的考证复原。正反面共用底图，翻面后由脚本更换数值与字色。

经典按钮目前沿用原棋子的局部坐标范围，前面高度 `0.11`、后面 `-0.01`、缩放 `0.5`。字体和位置以你的同类方形棋子为基准。HTML 预览能检验文字布局和不同显示大小，但不能代替 TTS 实际渲染；不同模型的底图方向、厚度或局部尺寸仍可能需要调整 `createModernUnitCounter` 中的位置与字号。它与地图旗的 Object UI 独立，不修改背面済印的 `1 / -0.09` 校准值。
