# v2.14.7：背面色带改用原生 UI 绘制

用户已在游戏里确认 v2.14.6 仍显示白色。最新存档也确认使用了该版本，因此上一版的资源名绑定修正不足以解决问题，不能称为实机修复成功。

## 本次处理

背面不再加载、绑定任何色带 PNG，而是用原生 UI Panel 的颜色直接绘制色带：

- 琥珀与朱红分别采用轻微的上下渐变。
- 十二条高 2 像素的色块在同一个 Canvas 内拼成 144 × 24 的短条，端部略收窄。
- 图片字段为空，颜色由每条 Panel 的 `color` 明确指定；不存在彩色色带 PNG 下载失败后露出白色占位图的步骤。
- 满士气、士气归零或敗走时隐藏；受损程度仍按本面的士气上限判断。
- 只有跨越琥珀／朱红状态时才更新渐变颜色；普通扣减不重建 UI 或重载素材。
- 不增加贴花或高度层，沿用 `-0.099` 和原来的位置。

正面仍使用现有 PNG，其他背面数字、底栏、未／済和点击按钮保持原来的显示方式。三种新增兵种继续包含在本版。

## 使用

打开 `Global_完整替换版_v2.14.7.txt`，在正文全选复制，然后在 TTS 的 Global Lua 代码框内全选替换，点击 Save & Play。

不需要上传新素材，不需要更换色带地址。`UNIT_MORALE_BAND_IMAGES` 两条地址现在只服务于正面；即使清空它们，背面的原生色带仍可显示。

長柄足軽背面应为：5 隐藏，4／3 琥珀，2／1 朱红，0 敗走。

本次检查包括 Lua 编译、实际交付 TXT 一致性、原生色块布局和颜色、阈值切换，以及删除色带图片配置后背面仍显示的回归验证。当前可用工具未连接到 TTS 实机渲染，因此仍需在游戏里确认实际显示；不把模拟检查表述为已完成游戏内视觉验证。
