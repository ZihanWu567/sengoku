# Photoshop 图层配对导出

将“图层 1”至“图层 8”分别与公共的“图层 9”组合，导出 8 张 PNG。保留原画布大小和现有透明区域，不修改原 PSD。

## 下载

- [export-layers.jsx](export-layers.jsx)：供 Photoshop 直接运行的脚本。
- [export-layers.txt](export-layers.txt)：内容相同的记事本版本；使用前将扩展名从 `.txt` 改为 `.jsx`。

在 GitHub 打开上述文件，点击文件工具栏中的 **Download raw file（下载原始文件）** 按钮，保存到电脑。

## 准备和运行

1. 在桌面版 Photoshop 中打开 PSD，并先保存自己的修改。
2. 将 8 个待组合图层命名为 `图层 1`、`图层 2`……`图层 8`，公共素材命名为 `图层 9`。每个名称应当唯一。脚本按名称识别，允许名称中的空格，不按图层排列顺序计数。
3. 调整好图层的位置、尺寸和上下遮挡顺序；脚本不会自动对齐或抠图。目标也可以是图层组，但“图层 9”和其他目标不能互相包含。
4. 文档使用 RGB 或灰度模式、8 位或 16 位/通道。
5. 选择 **文件 → 脚本 → 浏览**，打开下载的 `export-layers.jsx`。
6. 选择输出位置。脚本会创建新的子文件夹，保存 `图层 1_图层 9.png` 至 `图层 8_图层 9.png`。

每张 PNG 是对应两个目标的合成图，可以重新拖入 PS 继续组合；不会生成带可编辑原图层的 PSD。其他图层会在导出副本中隐藏，因此依赖其他图层的调整或剪贴效果可能与原文档整体显示不同。

以后更换公共素材时，给旧的“图层 9”改名，再将新素材命名为“图层 9”即可复用。
